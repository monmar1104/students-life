# Lekcja 6. Tablice i lista ocen

To kompletna, działająca wersja **po lekcji 6**, zawierająca również rozwiązania opisanych tu ćwiczeń i pracy domowej, jeśli są częścią tego etapu. Otwórz `index.html` w przeglądarce; Bootstrap jest pobierany z internetu. Nie potrzeba npm ani budowania projektu.

## Praktyczny początek — 0–10 min

Zmień zakres przykładowej pętli i sprawdź wartości graniczne.

Punktem wyjścia jest katalog lesson3. Uczeń pracuje na kopii poprzedniej wersji. Nie pokazuj gotowego rozwiązania z tego katalogu przed samodzielną próbą.

## Omówienie — 10–15 min

Uruchomcie rozwiązanie ucznia, porównajcie wyniki z wymaganiami i naprawcie błąd na konkretnych danych.

## Nowa wiedza — 15–22 min

Tablica, push, pop, length, join.

## Rozbudowa — 22–40 min

Zapisywanie ręcznie wybranych ocen w tablicy; wyświetlanie jako tekst w istniejącym HTML i usuwanie ostatniej oceny.

## Sprawdzenie działania — 40–45 min

Dodaj 3, 4, 5 → lista 3, 4, 5; usuń ostatnią → 3, 4; pusta lista nie powoduje błędu.

## Zadanie domowe / dalsza modyfikacja

Dopisz obliczanie sumy ocen w pętli.

## Zasada kodu

HTML definiuje interfejs. Bootstrap odpowiada za wygląd. JavaScript służy do obliczeń, zdarzeń i danych. Szablony powtarzalnych pozycji pojawiają się dopiero w lekcji 9. Dane są w pamięci i znikają po odświeżeniu.
