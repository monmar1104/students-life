# Lekcja 5 - tablice, lista ocen i statystyki

Punkt startowy: [start/index.html](start/index.html). Karta ucznia jest wyłącznie w [start/KARTA-UCZNIA.pdf](start/KARTA-UCZNIA.pdf). W tym katalogu znajduje się gotowe rozwiązanie.

Uczeń zna pętlę for i walidację pustego wyboru oceny. Starter zawiera te elementy, oba kalkulatory oraz cały HTML. Tablice są wprowadzane od podstaw. Do wykonania: wspólna tablica grades, dodawanie, usuwanie ostatniej oceny, lista i licznik, średnia, najwyższa ocena oraz liczba ocen co najmniej 4. Statystyki aktualizują się po każdej zmianie listy, również po usunięciu ostatniej oceny.

To kontynuacja niedokończonej części lekcji 4 i zakres wcześniejszej lesson7. Lesson6 i lesson7 pozostają materiałami archiwalnymi. Kolejny nowy temat: obiekty z lesson8.

Otwórz index.html w przeglądarce. Bootstrap wymaga internetu. Dane są przechowywane w pamięci do odświeżenia strony.
