# Lekcja 10. Zapis danych i pełna aplikacja

To kompletna, działająca wersja **po lekcji 10**, zawierająca również rozwiązania opisanych tu ćwiczeń i pracy domowej, jeśli są częścią tego etapu. Otwórz `index.html` w przeglądarce; Bootstrap jest pobierany z internetu. Nie potrzeba npm ani budowania projektu.

## Praktyczny początek — 0–10 min

Sprawdź usuwanie przedmiotu wraz z ocenami i zachowanie jego zadań bez przypisanego przedmiotu.

Punktem wyjścia jest katalog lesson9. Uczeń pracuje na kopii poprzedniej wersji. Nie pokazuj gotowego rozwiązania z tego katalogu przed samodzielną próbą.

## Omówienie — 10–15 min

Uruchomcie rozwiązanie ucznia, porównajcie wyniki z wymaganiami i naprawcie błąd na konkretnych danych.

## Nowa wiedza — 15–22 min

localStorage, JSON.stringify/parse, try/catch, eksport i import plików.

## Rozbudowa — 22–40 min

Pełna finalna aplikacja z automatycznym zapisem, kopiami JSON i walidacją przywracanych danych.

## Sprawdzenie działania — 40–45 min

Dodaj oceny i zadanie, odśwież stronę — dane pozostają. Sprawdź też eksport i przywrócenie kopii.

## Zadanie domowe / dalsza modyfikacja

Rozbuduj aplikację o własną funkcję, np. ważone oceny lub filtrowanie zadań.

## Zasada kodu

HTML definiuje interfejs. Bootstrap odpowiada za wygląd. JavaScript służy do obliczeń, zdarzeń i danych. Szablony powtarzalnych pozycji pojawiają się dopiero w lekcji 9. Dane są zapisywane w localStorage.
