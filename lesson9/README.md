# Lekcja 9. Dynamiczne listy z szablonów HTML

To kompletna, działająca wersja **po lekcji 9**, zawierająca również rozwiązania opisanych tu ćwiczeń i pracy domowej, jeśli są częścią tego etapu. Otwórz `index.html` w przeglądarce; Bootstrap jest pobierany z internetu. Nie potrzeba npm ani budowania projektu.

## Praktyczny początek — 0–10 min

Uzupełnij formularz nowego przedmiotu, odrzucając puste nazwy i duplikaty.

Punktem wyjścia jest katalog lesson8. Uczeń pracuje na kopii poprzedniej wersji. Nie pokazuj gotowego rozwiązania z tego katalogu przed samodzielną próbą.

## Omówienie — 10–15 min

Uruchomcie rozwiązanie ucznia, porównajcie wyniki z wymaganiami i naprawcie błąd na konkretnych danych.

## Nowa wiedza — 15–22 min

template, cloneNode, querySelector, addEventListener i zdarzenia formularzy.

## Rozbudowa — 22–40 min

Dynamiczne przedmioty i oceny, usuwanie, zadania z terminami i ukończeniem. Struktura wszystkich wierszy jest w HTML. Dane są tylko w pamięci do odświeżenia.

## Sprawdzenie działania — 40–45 min

Dodaj i usuń przedmiot; dodaj zadanie i oznacz wykonane; nazwa <b>test</b> wyświetla się jako tekst. Po odświeżeniu dane znikają.

## Zadanie domowe / dalsza modyfikacja

Zastanów się, kiedy zapisywać dane po kliknięciach. Przygotuj listę miejsc zapisu.

## Zasada kodu

HTML definiuje interfejs. Bootstrap odpowiada za wygląd. JavaScript służy do obliczeń, zdarzeń i danych. Szablony powtarzalnych pozycji pojawiają się dopiero w lekcji 9. Dane są w pamięci i znikają po odświeżeniu.
