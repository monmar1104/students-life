# Lekcja 7. Średnia i przetwarzanie tablic

To kompletna, działająca wersja **po lekcji 7**, zawierająca również rozwiązania opisanych tu ćwiczeń i pracy domowej, jeśli są częścią tego etapu. Otwórz `index.html` w przeglądarce; Bootstrap jest pobierany z internetu. Nie potrzeba npm ani budowania projektu.

## Praktyczny początek — 0–10 min

Samodzielnie dopisz przycisk usuwania ostatniej oceny i odświeżanie listy.

Punktem wyjścia jest katalog lesson6. Uczeń pracuje na kopii poprzedniej wersji. Nie pokazuj gotowego rozwiązania z tego katalogu przed samodzielną próbą.

## Omówienie — 10–15 min

Uruchomcie rozwiązanie ucznia, porównajcie wyniki z wymaganiami i naprawcie błąd na konkretnych danych.

## Nowa wiedza — 15–22 min

Sumowanie i porównywanie elementów tablicy w pętli.

## Rozbudowa — 22–40 min

Średnia, liczba ocen, najwyższa ocena i liczba ocen co najmniej 4.

## Sprawdzenie działania — 40–45 min

3, 4, 5 → średnia 4; po usunięciu 5 → 3,5; pusta lista → —.

## Zadanie domowe / dalsza modyfikacja

Zaplanuj, jakie dane opisują ocenę przypisaną do przedmiotu.

## Zasada kodu

HTML definiuje interfejs. Bootstrap odpowiada za wygląd. JavaScript służy do obliczeń, zdarzeń i danych. Szablony powtarzalnych pozycji pojawiają się dopiero w lekcji 9. Dane są w pamięci i znikają po odświeżeniu.
