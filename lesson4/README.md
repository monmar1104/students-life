# Lekcja 4 — pętla for i tablice

Punkt startowy: [start/index.html](start/index.html). Karta ucznia z teorią, przykładami, zadaniami i testami jest tylko w [start/KARTA-UCZNIA.pdf](start/KARTA-UCZNIA.pdf). Ten katalog zawiera gotowe rozwiązanie prowadzącego.

## Cel

Wprowadzić od podstaw pętlę for, uzupełnić tabelę ocen i dodać listę ocen przechowywaną w tablicy. Lista pozwala dodawać ocenę, usuwać ostatnią, pokazywać wszystkie wartości i ich liczbę.

## Zakres

- Powtórka: parametry, return i gradeFromPercentage w showExamples.
- for: początek, warunek, krok; uzupełnianie istniejących komórek HTML.
- Tablice liczb: [], indeksy, length, push, pop i join.
- Jedna funkcja renderGrades odświeża listę po każdej zmianie.
- Walidacja: brak wybranej oceny nie zmienia listy.

Bazą są ukończone funkcje lekcji 3 z prefiksami math- i polish-. Niezrealizowane zadanie pętli zostało przeniesione do tej lekcji. Zakres tablic odpowiada dotychczasowej lesson6. Oryginalny katalog lesson6 pozostawiono do porównania; następny etap rozszerzający listę to lesson7 (średnia i statystyki).

HTML w start i w rozwiązaniu jest identyczny. Uczeń dopisuje wyłącznie JS. Zaliczenie nadal następuje od 40%, a dane listy są przechowywane w pamięci do odświeżenia strony. Gotowe rozwiązanie obejmuje zadania podstawowe; ćwiczenia oznaczone jako dodatkowe służą do dalszej pracy.
