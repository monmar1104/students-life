# Lekcja 4 — start ucznia

Otwórz index.html i korzystaj z KARTA-UCZNIA.pdf. HTML zawiera oba kalkulatory, tabelę, skalę, przyciski oraz nowy moduł listy ocen. Wszystkie zadania wykonujesz w script.js.

Działa kod ukończony podczas lekcji 3: obliczenia, oceny, walidacja i czyszczenie. Prefiksy przedmiotów to math- i polish-. Zaliczenie następuje od 40%.

Do uzupełnienia są:

1. showExamples() — praktyczna powtórka funkcji z parametrami, bez pętli.
2. generateTable() — nowe zadanie z for, od 0 do 100 co 10.
3. Jedna pusta tablica grades poza funkcjami.
4. renderGrades() — tekst listy i licznik.
5. addGrade() — wybór oceny 1–6, walidacja, push i odświeżenie.
6. removeLastGrade() — pop i odświeżenie, także przy pustej liście.

Przed ukończeniem zadań przyciski powtórki, tabeli i listy nie wykonują nowych działań. Nie trzeba zmieniać HTML. Rozwiązanie prowadzącego jest katalog wyżej.
