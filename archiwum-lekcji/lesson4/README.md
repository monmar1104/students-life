# Lekcja 4. Funkcje z parametrami

To kompletna, działająca wersja **po lekcji 4**, zawierająca również rozwiązania opisanych tu ćwiczeń i pracy domowej, jeśli są częścią tego etapu. Otwórz `index.html` w przeglądarce; Bootstrap jest pobierany z internetu. Nie potrzeba npm ani budowania projektu.

## Praktyczny początek — 0–10 min

Dodaj drugi kalkulator na podstawie istniejącego i znajdź fragmenty, które się powtarzają.

Punktem wyjścia jest katalog lesson3. Uczeń pracuje na kopii poprzedniej wersji. Nie pokazuj gotowego rozwiązania z tego katalogu przed samodzielną próbą.

## Omówienie — 10–15 min

Uruchomcie rozwiązanie ucznia, porównajcie wyniki z wymaganiami i naprawcie błąd na konkretnych danych.

## Nowa wiedza — 15–22 min

Parametry funkcji oraz return z wartością.

## Rozbudowa — 22–40 min

Wspólne funkcje obliczeń, formatowania i oceny. Dwa formularze korzystają z tej samej logiki.

## Sprawdzenie działania — 40–45 min

35/50 w obu kalkulatorach → 70% i ocena 4; wyczyszczenie jednego nie czyści drugiego.

## Zadanie domowe / dalsza modyfikacja

Dodaj funkcję pokazującą trzy przykładowe oceny dla 40, 70 i 95%.

## Zasada kodu

HTML definiuje interfejs. Bootstrap odpowiada za wygląd. JavaScript służy do obliczeń, zdarzeń i danych. Szablony powtarzalnych pozycji pojawiają się dopiero w lekcji 9. Dane są w pamięci i znikają po odświeżeniu.
