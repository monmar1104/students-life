To kompletna, działająca wersja **po lekcji 3**, zawierająca również rozwiązania opisanych tu ćwiczeń i pracy domowej, jeśli są częścią tego etapu. Otwórz `index.html` w przeglądarce; Bootstrap jest pobierany z internetu. Nie potrzeba npm ani budowania projektu.

## Praktyczny początek — 0–10 min

Dodaj informację dla wyniku 100% oraz sprawdź reset formularza.

Punktem wyjścia jest katalog lesson2. Uczeń pracuje na kopii poprzedniej wersji. Nie pokazuj gotowego rozwiązania z tego katalogu przed samodzielną próbą.
