# Lekcja 5. Pętla for i tabela wyników

To kompletna, działająca wersja **po lekcji 5**, zawierająca również rozwiązania opisanych tu ćwiczeń i pracy domowej, jeśli są częścią tego etapu. Otwórz `index.html` w przeglądarce; Bootstrap jest pobierany z internetu. Nie potrzeba npm ani budowania projektu.

## Praktyczny początek — 0–10 min

Dodaj przycisk wywołujący funkcję gradeFromPercentage dla trzech przykładowych wyników.

Punktem wyjścia jest katalog lesson4. Uczeń pracuje na kopii poprzedniej wersji. Nie pokazuj gotowego rozwiązania z tego katalogu przed samodzielną próbą.

## Omówienie — 10–15 min

Uruchomcie rozwiązanie ucznia, porównajcie wyniki z wymaganiami i naprawcie błąd na konkretnych danych.

## Nowa wiedza — 15–22 min

Pętla for.

## Rozbudowa — 22–40 min

Stała tabela HTML dla 0–100% co 10 punktów; JS uzupełnia tylko oceny w istniejących komórkach.

## Sprawdzenie działania — 40–45 min

Tabela ma 11 wierszy: 0% → 1, 50% → 2, 100% → 6.

## Zadanie domowe / dalsza modyfikacja

Zmień tabelę na krok 5%, dodając komórki w HTML i zmieniając pętlę.

## Zasada kodu

HTML definiuje interfejs. Bootstrap odpowiada za wygląd. JavaScript służy do obliczeń, zdarzeń i danych. Szablony powtarzalnych pozycji pojawiają się dopiero w lekcji 9. Dane są w pamięci i znikają po odświeżeniu.
